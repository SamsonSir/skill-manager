# Joker陌生领域资料转化

当用户要快速进入陌生专业领域、理解客户材料或把长资料改写成团队入门材料时使用。普通摘要、简单概念解释、会议纪要和短文改写不使用。

## 工作方式

1. 识别资料类型、目标读者、使用目的和需要达到的实际能力。
2. 选择模式：默认先给理解规划；用户要求直接完成时，在内部完成规划并直接交付。
3. 找出理解主线所必需的核心概念、案例、前置知识和认知Gap，不追求无意义的“穷举全部”。
4. 按认知顺序重组资料，补足推理桥梁，保留有价值的试错过程。
5. 原资料未说明的事实不得凭连贯性补写；外部补充必须核查并标明来源，推断必须明确标记。
6. 交付前按能力结果验收，不声称读者已达到无法测量的“专家百分比”。

详细流程读取 [references/workflow.md](references/workflow.md)。写作与验收读取 [references/quality.md](references/quality.md)。只处理简单概念时不要加载这些参考文件。
