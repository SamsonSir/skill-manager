# 资料转化流程

## 输入识别

- 文档、网页：保留标题层级、论点、证据和引用。
- PDF：同时检查正文、表格、图示和附录；扫描件只有在视觉读取不足时才补OCR。
- 视频：结合字幕与关键视觉演示，不把“画面里有一张图”当作解释。
- 录音：转写后处理说话人、口语指代、术语和话题跳跃。
- 多份资料：去重，保留来源，指出冲突和未核实内容。

## 理解规划

输出并按任务需要决定是否等待确认：

1. 一句话主题和它解决的根本问题。
2. 核心概念及其因果、并列或递进关系。
3. 推荐的认知展开顺序。
4. 关键案例及其解释目标。
5. 外行容易卡住的前置知识和逻辑跳跃。
6. 读者完成后应具备的可观察能力。

## 正文组织

围绕“困惑、机制、案例、对比、应用、边界”自然推进。每个核心概念按需要讲清：是什么、为什么重要、怎么判断、怎么用、常见错误和适用边界。
