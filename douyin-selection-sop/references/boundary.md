# 能力边界与已知限制

> 最后更新：2026-04-18

## 当前能力边界

### ✅ 已支持

- `compass -> 商品榜单 -> 短视频榜 -> 完整商品名搜索 -> 页面数据层提取 video_list` 视频提取链路
- `data -> tooltip fallback` 双轨提取模式
- 批量任务（jsonl/csv）执行、结果汇总、失败重跑
- manifest 生成、全局汇总、并发下载
- 飞书重复记录更新（不改 created_at）
- 爆品预筛前置到飞书入库前
- 极简 `商品报告_YYYY-MM-DD.md` 汇总输出（按日期聚合商品名 + 好货链接）
- 飞书选品清单读写

### ❌ 未内置

- **自动爆品潜质量化打分**：目前仍主要依赖 AI 综合判断，尚未内置稳定量化评分卡模型

### 🚫 明确不属于本 skill

- **供应链比价**：1688 等货源侧比价不纳入 `douyin-selection-sop`
- **自动定价**：售价推导与利润测算不纳入 `douyin-selection-sop`

## 给龙虾直接使用的条件

- Skill 文件在 `~/.agents/skills/` 下（非 symlink）
- 运行环境有 `agent-browser`、`jq`、curl
- Chrome/CDP 9222 已登录抖音罗盘并可访问 compass 页面
- 飞书权限与 Base 可访问（若启用回写）

## 已知问题 & 踩坑记录

1. **详情图误抓**：好货页详情区图片选择器可能抓到非目标区域图片，需校验图片内容是否为真实详情图（已遇坑：2026-04-12 亿来喜盘香，首次抓到错误图片，修正后重抓）
2. **视频 URL 短时有效**：获取 `video_play_url` 或 `video.currentSrc` 后必须立即下载，不能长期复用旧 manifest
3. **Chrome 登录态**：需 Canary + ChromeMP 配置，普通 Chrome profile 可能无抖店登录态
4. **飞书重复记录**：同一商品可能因多次采集重复入库，需按商品名去重更新而非新增

3. 增加按店铺维度的视频命名别名配置
