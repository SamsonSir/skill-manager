## 关键导航路径（必读）

### 1. 进入短视频榜

```
抖店后台（fxg.jinritemai.com）
  → 顶部「商品」
  → 左侧「商品榜单」
  → 右侧 tab 切换到「短视频榜」
```

**直达 URL：** `https://compass.jinritemai.com/shop/chance/rank-product`

确认方式：「短视频榜」tab 高亮，页面说明含「通过短视频挂车渠道成交商品的排行榜」。

> 罗盘有 7 个 tab（总榜/搜索榜/直播榜/商品卡榜/达人带货榜/短视频榜/实时爆品挖掘榜），必须切到「短视频榜」。

#### 固定导航策略

执行前先查 `http://127.0.0.1:9222/json/list`：

1. 已有 `compass.jinritemai.com/shop/chance/rank-product` tab → 直接复用。
2. 当前在 `fxg.jinritemai.com`、罗盘首页或其他罗盘页面 → 先用 CDP `Page.navigate` 直达 `https://compass.jinritemai.com/shop/chance/rank-product`。
3. 直达失败才点页面入口，入口词只限：`商品`、`商品榜单`、`机会榜单`、`短视频榜`。
4. 超过 2-3 分钟仍未进入榜单页，停止，让用户手动打开目标 URL；不要继续盲点。

不要把以下页面误判为可采集页：

- `fxg.jinritemai.com` 抖店首页
- `compass.jinritemai.com` 罗盘首页/概览
- 非 `rank-product` 的罗盘分析页
- `rank-product` 里未切到 `短视频榜` 的其他榜单 tab

### 2. 打开好货商品详情页

在短视频榜中点击**商品名称**跳转好货详情页。
URL 格式：`haohuo.jinritemai.com/ecommerce/trade/detail/index.html?id={商品ID}`

页面结构：左侧主图轮播 / 右侧标题价格店铺信息 / 下方详情图规格参数用户评价

### 3. 带货短视频采集入口

**入口仅在短视频榜列表页。** 在「带货短视频」列 hover 数字 → 弹出 tooltip 显示视频封面缩略图 → 点击缩略图触发预览。

> 视频不提供直接下载链接。URL 从预览时加载的网络请求获取（video.currentSrc），CDN 链接约 30 分钟有效，获取后立即下载。

## 异常处理

- **罗盘登录态过期** → 提示用户重新登录 Chrome CDP 9222，或使用 agent-browser 重新进入
- **某条商品抓取失败** → 跳过继续，记录失败原因到日志，不中断整体流程
- **飞书写入权限不足** → 报错并停止，提示检查 Base 权限
- **视频 CDN 下载失败** → 重试一次仍失败则跳过，标注「视频下载失败」
- **所有平台不可用** → 写入飞书状态为「失败」，通知用户具体原因
