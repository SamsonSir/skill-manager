# 十大分析维度（上）· 视觉层

分析维度分两组。本文件覆盖 A–F（视觉层），`references/style-mood-symbolism.md` 覆盖 G–J（语义层）。

每一项都要标注可信度：`OBSERVED` / `INFERRED` / `UNCERTAIN`。见 `references/uncertainty-and-safety.md`。

---

# A. SUBJECT｜主体

## 识别项

| 项 | 内容 |
| --- | --- |
| 类型 | 人物 / 动物 / 物体 / 建筑 / 环境 |
| 数量 | 单人 / 多人 / 群像，具体数字 |
| 年龄感 | 具体区间，写 `late 20s` 不写 `young` |
| 性别表现 | 外观呈现 |
| 体型 | 身高感、肩宽、体态 |
| 外貌 | 脸型、五官、肤色、特征标记（痣、疤、雀斑） |
| 发型 | 形态 + 束法 + 长度 + 发色 |
| 服装 | 逐件：类型、颜色、材质、剪裁、磨损 |
| 配饰 | 位置 + 材质，逐件列出 |
| 姿态 | 身体朝向、脊柱曲线、肩线、重心 |
| 动作 | 正在进行的动作及其中间状态 |
| 表情 | 可拍摄的肌肉细节，不写情绪形容词 |
| 视线方向 | 看向哪里（画面内 / 画面外 / 镜头） |
| 身体朝向 | 相对镜头 |
| 人物关系 | 多人时的互动、距离、视线关系 |

## 表情写法

**禁止情绪形容词**，转译为可拍摄细节：

| 情绪 | 可拍摄细节 |
| --- | --- |
| 悲伤 | 眉头上挑内收，眼睑下垂，嘴角下压 |
| 紧张 | 下颌肌肉绷紧，喉结移动，手指收紧 |
| 放松 | 肩线下沉，眼睑自然，唇部无张力 |

## 视线与朝向

**这三项决定了画面像不像**，必须写：

- 视线方向：`gazing off frame right` / `direct eye contact with the camera` / `looking down at hands`
- 身体朝向：`facing the camera` / `three-quarter turned away` / `back to camera`
- 头部角度：`head turned approximately 15 degrees to frame right`

**角度只能给近似值。** 看不出来就标 `UNCERTAIN`，不要硬编。

# B. COMPOSITION｜构图

## 分析项

| 项 | 内容 |
| --- | --- |
| 方向 | 横向 / 纵向 |
| 主体位置 | 九宫格哪个位置，占画面比例 |
| 前中后景 | 三层分别写 |
| 视觉中心 | 观众第一眼看哪里 |
| 留白 | 在哪一侧，占多少 |
| 对称性 | 对称 / 非对称 |
| 构图法 | 三分法 / 中心 / 引导线 / 框架 / 对角线 / 黄金分割 |
| 景深层次 | 哪层清晰，哪层虚 |
| 人物占画面比例 | 百分比 |
| 人物转头角度 | 近似值 |
| 身体朝向 | 相对镜头 |
| 视线方向 | 看向哪里 |

## 角度表达参考

```
head turned approximately 15 degrees
body rotated approximately 30 degrees
three-quarter view
profile view
frontal view
back view
```

**不要假装精确到无法从图片判断的程度。** `approximately` 是必要的限定词。

# C. PHOTOGRAPHY｜摄影分析

## Camera

| 项 | 内容 |
| --- | --- |
| 相机高度 | 平视 / 眼高 / 胸高 / 腰高 / 地面 / 高处 |
| 相机位置 | 正面 / 侧面 / 背后 / 上方 / 下方 |
| 相机角度 | 平视 / 俯拍 / 仰拍 / 荷兰角 |
| 拍摄距离 | 近 / 中 / 远，或近似米数 |
| 取景 | 特写 / 近景 / 中景 / 全景 / 远景 |
| 透视 | 透视强度、消失点方向、有无畸变 |

## Lens `[INFERRED]`

**焦段无法直接测量，一律标 INFERRED 并给依据。**

| 判断依据 | 推测焦段 |
| --- | --- |
| 强透视、边缘形变、空间被拉开 | 24mm |
| 小广角，环境与人关系自然 | 35mm |
| 视角自然无夸张 | 50mm |
| 面部透视讨喜、背景压缩 | 85mm |
| 强压缩、背景高度虚化 | 105mm |
| 极强压缩、远景被拉近 | telephoto compression |

写法：`85mm [INFERRED] — 依据：面部无透视形变，背景压缩明显`

## Depth of Field

| 档位 | 判断特征 |
| --- | --- |
| shallow DOF | 只有眼睛清晰，耳后开始虚 |
| medium DOF | 面部纵深内清晰，发梢开始虚 |
| deep DOF | 全画面清晰 |
| background separation | 主体与背景的虚化程度差 |
| bokeh characteristics | 散景形状（圆形/多边形）、边缘硬度、有无二线性 |

## Image Formation

| 项 | 内容 |
| --- | --- |
| dynamic range | 高光与暗部细节保留程度 |
| sharpness | 锐度 |
| micro-contrast | 微观对比度 |
| film grain | 颗粒感 |
| highlight roll-off | 高光过渡是否柔和 |
| natural motion blur | 运动模糊 |
| chromatic aberration | 色差（边缘紫边/绿边） |
| lens flare | 耀斑 |
| atmospheric perspective | 大气透视（远处雾化） |

# D. LIGHTING｜光影分析

## 光源类型

key light · fill light · rim light · backlight · side light · top light · practical lights · natural sunlight · overcast lighting · studio lighting · golden-hour lighting · low-key / high-key lighting

## 描述项

| 项 | 内容 |
| --- | --- |
| 光源方向 | 从哪个方位来，写方向（from camera left 等） |
| 光线软硬 | 硬光（阴影边缘锐利）/ 柔光（过渡绵长）/ 混合 |
| 色温 | 冷暖倾向 `[OBSERVED]`，具体 K 值 `[INFERRED]` |
| 阴影方向 | 投影朝向 |
| 阴影密度 | 阴影内细节保留程度 |
| 高光区域 | 高光落在哪里 |
| 轮廓光 | 有无、在哪一侧 |
| 环境反射光 | 地面/墙面/水面是否产生补光 |

**灯位与灯型一律标 `[INFERRED]`**——画面外的灯你看不见。

# E. COLOR｜色彩分析

## 提取项

| 项 | 内容 |
| --- | --- |
| dominant colors | 主色，占画面面积最大的 |
| secondary colors | 次色 |
| accent colors | 点缀色 |
| warm / cool relationship | 冷暖关系与分布 |
| saturation | 饱和度 |
| contrast | 对比度 |
| brightness | 整体明度 |
| cinematic color grading | 分级风格（Teal & Orange / 单色 / 低饱和等） |

**最终选出 3–7 个主要色彩**，写进 JSON 的 `color_palette`。

## 写法

```
color_palette: ["deep crimson", "charcoal black", "warm ivory", "muted sage"]
```

用具体色名，不用 `red`、`blue` 这种泛称。

# F. MATERIAL & TEXTURE｜材质与纹理

## 识别项

skin · hair · fabric · leather · metal · glass · wood · stone · concrete · plastic · water · dust · smoke · paper · environmental surfaces

## 硬性要求

**不要只写 "high detail"。** 必须解释：

1. 细节**是什么**
2. 这些细节**为什么**会产生这种视觉质感

```
✅ natural skin pores, subtle facial micro-texture, fine hair strands,
   realistic fabric weave, soft specular highlights, slightly weathered surface details
❌ highly detailed, high detail, ultra detailed, extremely detailed
```

## 各类材质的具体写法

| 材质 | 具体描述 |
| --- | --- |
| 皮肤 | visible pores, fine facial hair, subtle subsurface scattering, natural oil sheen |
| 头发 | individual strands catching the light, matte roots to glossy ends, slight flyaways |
| 织物 | visible weave, fiber direction, natural drape and fold shadows, worn at the edges |
| 皮革 | fine grain, creases at flex points, semi-gloss patina |
| 金属 | brushed grain direction, specular edge highlights, micro-scratches |
| 玻璃 | transmission with internal refraction, edge highlights, surface reflections |
| 木 | grain direction, open pores, worn finish |
| 石/水泥 | surface pitting, aggregate texture, chalky matte finish |
| 水 | surface tension, ripple patterns, reflection distortion |
| 烟尘 | light-scattering particles, density gradient |
