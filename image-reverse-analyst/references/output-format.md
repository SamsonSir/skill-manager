# 固定输出格式

**每次分析图片必须严格按三段输出。不得增删区块，不得调整顺序。**

---

## ① 风格分析

```
① 风格分析

风格：XXX

风格特点：
* XXX
* XXX
* XXX
* XXX

为什么判断为这种风格：
XXX

相近的视觉语言：
XXX
```

**硬性要求**：

- 标题必须就是「① 风格分析」
- 第二行必须就是「风格：XXX」，风格名要准确，不用泛称
- 「风格特点」3–5 条，都是可观察的视觉事实
- 「为什么判断为这种风格」给出推理链，不是贴标签
- 「相近的视觉语言」用「存在相似之处」的表述，**不声称是某位艺术家的作品**
- 没有相近的视觉语言可写时，写「无明显相近的视觉语言」

**风格分析必须放在最前面。** 这是本技能的固定结构——先定风格，再展开其他分析。

---

## ② 图片生成提示词

```
② 图片生成提示词

<一份完整、可直接使用的中文 Prompt，一段，不分行>
```

**硬性要求**：

- **用中文**
- 必须覆盖 14 个要素：主体 + 外观 + 动作 + 环境 + 构图 + 摄影 + 镜头 + 光影 + 色彩 + 材质 + 风格 + 氛围 + 细节 + 画质
- 按 12 级优先级排序（见 `references/reverse-prompt.md`）
- 必须是自然语言，不是关键词堆叠
- 写成一段，不换行、不用 bullet
- 不含 masterpiece / best quality 这类空词
- INFERRED 参数用约数或区间

---

## ③ JSON Prompt

```
③ JSON Prompt

{
  "scene": "...",
  ...
}
```

**硬性要求**：

- **全英文**，一个中文字符都不能有
- 严格按固定 schema，不增删字段
- valid JSON：双引号、无注释、无尾逗号、无 Markdown
- 缺项填 `"None"`，不编造
- 无象征时用固定句式

完整 schema 见 `references/json-schema.md`。

---

## 完整输出骨架

```
① 风格分析

风格：cinematic editorial portrait

风格特点：
* 硬质单侧光源，阴影边缘锐利
* 冷蓝灰基调，仅暖橙点光作为对比
* 浅景深，焦点锁定眼部
* 主体压左三分点，右侧留白朝向视线方向

为什么判断为这种风格：
画面采用硬质侧光而非柔光箱的均匀照明，阴影边缘清晰可见……
色彩上整体冷调但保留单一暖色锚点，这是典型的青橙分级……

相近的视觉语言：
与当代时尚杂志的低调光人像存在相似之处。

② 图片生成提示词

一位 20 代后半的女性以四分之三侧脸站在窗边……（完整一段中文）

③ JSON Prompt

{
  "scene": "...",
  "subjects": [...],
  ...
}
```

---

## 语言规则

| 区块 | 语言 |
| --- | --- |
| ① 风格分析 | 中文 |
| ② 图片生成提示词 | **中文** |
| ③ JSON Prompt | **全英文** |

**注意：中文提示词与英文 JSON 的语言是固定的，不要颠倒。** 这是本技能的特色——用户拿中文提示词喂中文模型，拿 JSON 喂下游管线。

---

## 输出纪律

- [ ] 只有三段，没有第四段
- [ ] 没有"我为你分析了……"这类说明性文字
- [ ] 没有在末尾追加总结或建议
- [ ] 三段标题格式完全一致
- [ ] ② 是中文，③ 是全英文

---

## 用户追加要求时

| 用户说 | 处理 |
| --- | --- |
| 「只要 JSON」 | 只输出第三段，其余省略 |
| 「只要提示词」 | 只输出第二段 |
| 「不用分析」 | 输出第二段 + 第三段 |
| 「要英文提示词」 | 第二段改用英文，其余不变 |
| 「加一段负面提示词」 | 在第三段后追加，但要说明这是用户追加的 |

**用户没提要求时，永远输出完整三段。**
