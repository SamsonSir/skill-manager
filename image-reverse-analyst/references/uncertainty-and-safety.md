# 可信度分级 & 安全替换

---

# 一、三级可信度

**每一项分析都必须标注属于哪一级。** 这是本技能的纪律底线。

| 级别 | 含义 | 处理方式 |
| --- | --- | --- |
| `OBSERVED` | 图片中可以直接观察到的信息 | 准确描述，可以写进 Prompt |
| `INFERRED` | 根据摄影语言、视觉特征推测的信息 | 必须给出推测依据，Prompt 里用约数 |
| `UNCERTAIN` | 无法从图片确定的信息 | 不写进 Prompt，或写得极模糊 |

---

## 哪些属于 OBSERVED

画面里能直接看见的一切：

- 主体、数量、外观、服装、配饰
- 姿态、视线方向、身体朝向
- 前中后景内容、构图、主体占比
- 光源方向、阴影方向、高光位置
- 色彩、明度、饱和度
- 材质纹理
- 文字内容（能看清的部分）

## 哪些属于 INFERRED

**物理上无法从单张画面确定，必须标 INFERRED：**

| 项 | 推测依据 |
| --- | --- |
| 焦段 | 透视压缩程度、面部形变、画面容纳范围 |
| 光圈值 | 景深过渡范围、虚化程度 |
| 快门速度 | 运动模糊程度 |
| ISO | 噪点水平 |
| 灯位与灯型 | 阴影方向与光质（画面外的灯看不见） |
| 色温 K 值 | 冷暖倾向 |
| 后期软件 | 视觉特征（无法确定工具） |
| 拍摄机型 | 几乎无法判断 |
| 色卡/分级 LUT | 只能描述结果，无法确定工具链 |

## 哪些属于 UNCERTAIN

- 看不清的文字内容
- 被遮挡或模糊的主体细节
- 画面外的事物
- 人物的具体年龄（只能给区间）
- 材质在画面中占比过小时

---

## 标注写法

```
焦段      [INFERRED] 85mm 左右 —— 依据：面部无透视形变，背景压缩明显，
                     人物与背景的尺度差被拉大
光圈      [INFERRED] f/4–f/5.6 —— 依据：面部纵深内保持清晰，
                     只有发梢开始虚化
文字内容  [UNCERTAIN] 招牌上的字迹部分模糊，可辨认出前两个字母
视线      [OBSERVED] 看向画面右侧，略低于水平线
```

---

## 最重要的表述纪律

**绝对不要声称：「这就是原始 Prompt。」**

**正确表述：**

> 这是根据最终图像反向重建的高概率 Prompt。

原因：图像是**多对一**的——不同的 Prompt 可以生成相似的图。任何反推都只能给出**高概率**的重建，不是原始输入。

### 该说与不该说

| 不该说 | 该说 |
| --- | --- |
| 这就是原始 Prompt | 这是根据最终图像反向重建的高概率 Prompt |
| 拍摄参数是 f/1.4 | 景深范围推测在 f/2 附近 |
| 用了 XX 软件调色 | 从色彩特征看接近 XX 类型的分级 |
| 这是 XX 的作品 | 与 XX 的视觉语言存在相似之处 |
| 焦段是 85mm | 焦段推测在 85mm 左右 |

# 二、安全替换

## 触发条件

原图片或用户要求中出现**敏感、不适宜或高风险**词汇。

## 处理四原则

1. **不重复输出敏感词** —— 不要在分析或 JSON 里复述原词
2. **不放入 JSON** —— JSON 是下游管线的输入，更不能带敏感内容
3. **使用安全、准确的视觉替代表达** —— 替代词要能描述视觉，不是含糊其辞
4. **尽可能保持原始视觉意图** —— 替换后画面应该还是那个画面

## 替代表达对照

| 原内容 | 安全替换 |
| --- | --- |
| 暴力冲突场面 | `intense confrontation` |
| 血腥/受伤 | `stylized action scene` |
| 危险生物 | `dramatic fantasy creature` |
| 恐怖人形 | `mysterious humanoid figure` |
| 身体异变 | `fictional transformation` |
| 露骨内容 | 描述氛围与构图，不描述身体 |
| 真实可识别的私人场所 | 泛化为同类场景 |
| 真实人物的负面情节 | 改为虚构角色 |

## 写法示例

```json
"scene": "an intense confrontation between two stylized figures in a dark interior"
```

而不是描述具体发生了什么。

**核心**：观众不需要看到细节，只需要"感觉到发生了"。暗示比直给更高级，也更安全。
