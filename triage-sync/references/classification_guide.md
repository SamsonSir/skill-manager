## 分类判断流程

### Step 1: 扫描关键词
使用正则表达式匹配文章内容中的关键词：
```bash
grep -qiE "(Claude Code|代码|编程|工程...)" "$file"
```

### Step 2: 按优先级匹配
更具体的分类放在前面，避免误分类：
1. Agent 技术（特定技术栈）
2. AI 工程实践（通用编程）
3. AI 产品与工具
4. AI 商业与转型
5. 知识管理
6. 工作流与方法论

### Step 3: 边界情况处理
- 如果文章同时匹配多个分类 → 优先匹配更具体的
- 如果不匹配任何分类 → 使用默认分类 "AI工程实践"
- 如果内容明显不属于任何分类 → 询问用户是否需要新建分类
