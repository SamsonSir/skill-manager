# 抽取规则说明

## 群聊精华抽取规则

### 信号特征与动作

| 信号特征 | 动作 | 示例 |
|---------|------|------|
| 长 prompt / 角色定义（"你是一位..."） | → 提炼为 `99_系统/提示词/<概念>.md` | "你是一位专业的代码审查专家，需要..." |
| GitHub 链接 + 项目说明 | → 追加到 `50_资源/项目雷达.md` | "这个项目很棒：https://github.com/..." |
| 工具配置 / shell 命令 / 技巧 | → 写入 `40_知识库/精华群聊/<日期>.md` | "用这个命令可以快速部署..." |
| 概念性洞察 / 金句 / 方案讨论 | → 写入 `40_知识库/精华群聊/<日期>.md` | "我觉得 AI 的核心价值在于..." |
| 课程/培训经验分享 | → 写入 `40_知识库/精华群聊/<日期>.md` | "AI 培训踩坑分享..." |
| `[图片]` / `[该消息类型暂不能展示]` | **直接丢弃** | [图片] |
| 纯表情 / 单字回复 | **直接丢弃** | 😊、👍、收到 |
| 闲聊水群（"在吗""收到""[强]"） | **直接丢弃** | 在吗？收到了！[强] |

---

### 抽取标准

**宁可严，不可滥**

一个原子笔记必须代表一个**完整的知识点**：
- ✅ 单条孤立消息（"我用 X"）不够格
- ✅ 必须有上下文/方案/对话链
- ✅ 必须有价值、可复用

**判断标准**：
- 能否独立理解？
- 是否有完整的上下文？
- 对未来是否有参考价值？
- 是否包含可操作的信息？

### 抽取颗粒度

**追求"日记式扫读"，不追求每条都做完整原子笔记**

- 一个主题 2-5 段说明就够
- 不要堆 bullet
- 重要金句保留 blockquote
- 代码/命令/链接原样保留

**示例**:
```markdown
## Claude Code 隐藏命令

> 按 Esc 两次可以回退上一步操作，非常实用！

这个技巧在写代码时很有用，特别是当你走错了方向想撤销的时候。比 git reset 更灵活，而且不改变文件状态。学会了之后，我发现开发效率提升了不少。

---

## 技能开发规范

> 技能的 description 要写得 "pushy" 一点，这样才能提高触发准确率。

我们在开发新技能时发现，如果 description 写得太通用，Claude 就不容易识别什么时候该用这个技能。现在我们的做法是把所有可能触发这个技能的场景都写进去，比如"当用户提到整理同步助手、归档微信记录、处理收件箱时都触发"。
```

## 公众号文章抽取规则

### 保留内容

**必须保留**:
- ✅ 完整的原文内容（不截断、不摘要化）
- ✅ 所有图片链接（`![](...)` 格式）
- ✅ 所有 Markdown 格式
- ✅ 原始 frontmatter（author, url, saved 等）

**可以移除**:
- ❌ 广告段落
- ❌ 导流二维码
- ❌ 底部推广链接

### TLDR 撰写指南

**目标**: 让 3 个月后的自己 30 秒能回想起这篇讲什么

**要素**:
1. 核心主题（一句话）
2. 关键结论（1-2 句）
3. 实用价值（1-2 句）

**示例**:
```
## TLDR
这篇文章介绍了 Claude Code 的 10 个隐藏命令，包括 /btw（并行插话）、/rewind（回退代码和对话）、/insights（使用习惯分析）等。这些命令能大幅提升开发效率，特别是 /btw 和 /rewind 在长会话中非常实用。建议每周跑一次 /insights 来优化自己的使用习惯。
```

---

### 核心观点提取指南

**数量**: 3-5 个观点

**要求**:
- 每个观点独立成行
- 用 bullet 格式
- 简洁明了（1-2 句）

**示例**:
```markdown
## 核心观点
- Claude Code 的更新速度极快，很多功能在更新日志里看不到，需要关注开发团队的 Twitter
- /btw 命令可以在不中断当前任务的情况下插话问问题，避免上下文污染
- /rewind 可以分别回退代码和对话，非常适合做实验和尝试不同方案
- /insights 能生成使用习惯报告，帮助发现重复性操作并推荐自定义命令
- /remote-control 让你可以在手机上远程操作 Claude Code，非常适合随时查看进度
```

## 常见错误

### ❌ 错误 1：抽取过于碎片化
**问题**: 每条消息都抽取
**解决**: 宁严勿滥，只抽取完整的知识点

### ❌ 错误 2：文章内容截断
**问题**: 只读前 50 行
**解决**: 必须读取完整文件内容

### ❌ 错误 3：图片链接丢失
**问题**: 过滤或替换图片链接
**解决**: 保留所有 `![](...)` 格式的图片链接

### ❌ 错误 4：分类错误
**问题**: 没有按优先级匹配
**解决**: 按优先级：Agent 技术 > AI 工程实践 > AI 产品 > AI 商业 > 知识管理 > 工作流

### ❌ 错误 5：源文件未归档
**问题**: 处理后没有移动源文件
**解决**: 必须移动到 99_系统/归档/ 对应目录
