# 公众号爆款文章写作技能

基于 2026 公众号推荐算法（完读率第一、社交传播第二、原创 3 倍权重、冷启动赛马机制）与六大爆款公式，一站式完成选题挖掘、爆款标题、钩子开头、高完读正文、转化结尾与合规自检，直接产出可发布的 10 万+ 潜力公众号文章。

## 能做什么

| 场景 | 用法 |
|---|---|
| 写公众号文章 | 「帮我写一篇关于 XX 的公众号文章，我的号是 XX 定位」 |
| 起标题 | 「这篇文章帮我起 10 个爆款标题」 |
| 做选题 | 「我是 XX 账号，给我 5 个本周选题」 |
| 改稿优化 | 「帮我把这篇改成公众号风格，阅读量太低」 |
| 合规检测 | 「帮我校验这篇有没有违规/会被限流的地方」 |

## 安装与使用

1. 在 WorkBuddy 技能市场或对话中安装本技能
2. 说出你的写作需求（主题/账号定位/目标）
3. 技能按「需求诊断→选题→标题→正文→排版→合规自检」流水线输出
4. 交付物：完整文章 + 10 个候选标题 + 合规自检清单
