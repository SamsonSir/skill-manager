# 公众号爆款文章结构拆解（开头/正文/结尾公式）

> 爆款文章不是灵感产物，而是公式产物。本文件给出可直接套用的四段式结构，保证「前 3 屏不流失、中段高完读、结尾高转化」。

## 一、开头公式（前 3 屏定生死）

**公式：场景代入 → 痛点共鸣 → 价值承诺**

- 第 1-2 句：具体场景/故事，让读者点头「对对对，就是我」
- 第 3-4 句：戳中痛点或损失，制造「不读就亏」
- 第 5 句：价值承诺「本文将给你 X 个方法，全部亲测有效，看完就能用」

反例（AI 味开头，禁用）：「随着社会的发展……」「在当今时代……」。
正例：「你是不是也有这样的经历：辛辛苦苦写了一篇公众号文章，发布后阅读量只有几十，转发更是个位数。明明内容很用心，为什么没人看？本文将告诉你 3 个让阅读量翻 10 倍的方法，全部亲测有效，看完就能用。」

## 二、正文公式（保完读）

**公式：观点 → 案例 → 小结（每个论点三段式）**

- 观点：一句话亮明论点，不绕弯
- 案例：真实案例/数据/故事佐证（越具体越好：有数字、有细节、有名字或可信匿名）
- 小结：一句话总结并过渡到下一论点

**完读率硬规则：**
1. 每段不超过 4 行（手机屏阅读）
2. 多用小标题拆结构，读者可扫读
3. 每 300 字至少一个信息增量点（新方法/新数据/新观点），不能是旧话重复
4. 穿插 2-3 句可转发金句并加粗（如「真正拉开差距的，从来不是上班的 8 小时，而是下班后的 2 小时」）
5. 一个论点讲完立刻进下一个，不恋战、不注水

## 三、结尾公式（高转化）

**公式：总结升华 → 互动引导 → 关注/在看转化**

- 总结升华：用 1-2 句话收拢全文价值（可点题金句）
- 互动引导：提一个读者想回答的问题，引导评论
- 转化：自然引导关注/在看/收藏，不硬广（「觉得有用，别忘了点个『在看』，后续会分享更多干货」）

## 四、四类内容的结构侧重

| 类型 | 开头侧重 | 正文侧重 | 结尾侧重 |
|---|---|---|---|
| 干货教程 | 痛点+承诺 | 分步骤、可执行 | 引导收藏+关注 |
| 观点评论 | 反常识观点 | 论证链+案例 | 引导讨论 |
| 情感故事 | 场景+共情 | 故事线+金句 | 情绪升华 |
| 行业洞察 | 数据/现象切入 | 分析+趋势判断 | 引导转发（身份表达） |

## 五、真人化/去 AI 味替换表

| AI 高频词（删除/替换） | 真人化替代 |
|---|---|
| 首先 / 其次 / 再次 | 直接切入场景 |
| 总而言之 / 综上所述 | 一句话收束 |
| 值得注意的是 | 划重点： |
| 综上所述 | （删除） |
| 在当今社会 / 随着时代发展 | （删除，直接写人） |
| 赋能 / 抓手 / 闭环 / 颗粒度 | 换成大白话 |
| 毋庸置疑 / 显而易见 | 说实话 / 讲真的 |

> 额外技巧：加入 1-2 处个人经历或「我也踩过坑」式自嘲，适度不完美才像真人。
