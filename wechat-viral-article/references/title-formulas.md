# 公众号爆款标题公式库（可直接套用）

> 用户看标题平均只花 0.3 秒决定是否点击。公众号平均打开率约 1.13%。标题长度建议 13-30 字，前 5-10 个字决定生死。写标题必须「具体、有利益点、不标题党」。

## 六大公式（每个给模板 + 案例）

### 公式 1：数字 + 痛点 + 解决方案（干货类首选）
模板：「X 个方法/技巧 + 解决 Y 痛点 + 获得 Z 结果」
- 3 个排版技巧，让你的公众号阅读量翻倍
- 我用 7 天，把公众号粉丝从 0 做到 1 万
- 3 年写了 500 篇公众号文章，我总结出这 10 条经验

### 公式 2：反常识 + 好奇心（观点类首选）
模板：打破认知 + 留一个「为什么」
- 为什么 90% 的公众号都做错了选题
- 日更的公众号反而做不起来，原因有 3 个
- 没花一分钱，我的公众号排版比付费用户还好看

### 公式 3：身份认同 + 场景（垂直号首选）
模板：身份标签 + 口语化 + 与读者对话
- 做公众号的姐妹们，这 3 个坑我真的踩怕了
- 打工人的下班后，才是拉开差距的地方

### 公式 4：故事悬念 + 情感共鸣
模板：半截故事 + 省略号/留白 + 让人想看完
- 我用了一个月免费编辑器后，再也没打开过付费版
- 那个坚持日更 300 天的朋友，今天停更了……

### 公式 5：提问式（教程号常用）
纯痛点疑问：「为什么……」「如何……」
- 新手小白如何写出 10W+ 的公众号文章？
自问自答（降低行动成本）：
- 设计 logo 很难吗？0 基础 3 分钟学会的办法

### 公式 6：紧跟热点 / 权威背书
模板：热点人物/机构 + 观点或启示
- 钟南山这张图疯传：84 岁再赴武汉，背后的真相是……
（注意：热点必须核实事实，禁止造热点、蹭不实热点）

## 公众号标题 5 条硬规则

1. **13-30 字**，前 10 个字放最核心信息（信息流里后半截常被折叠）
2. **具体可感知**：用数字、场景、人群词，拒绝「超好用」「很厉害」这类空形容词
3. **与正文一致**：标题承诺的，正文必须给到（标题与正文严重不符 = 标题党，被限流）
4. **禁用标题党词**：震惊、不看后悔、速看、删前速存、100% 等
5. **一次写 10 个再选**：单一标题很难最优，10 个中挑最能打的；必要时给 2 版让用户 A/B 测试

## 标题自检清单

- [ ] 前 10 字是否承载核心卖点？
- [ ] 有没有具体数字或场景（而非空形容词）？
- [ ] 读者 0.3 秒内能否判断「与我有关 / 对我有用 / 让我好奇」？
- [ ] 是否有标题党嫌疑 / 与正文脱节？
- [ ] 长度是否在 13-30 字？
- [ ] 是否命中一个明确公式（而非随意组合）？
