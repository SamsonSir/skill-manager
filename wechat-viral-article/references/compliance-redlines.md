# 公众号发布合规红线清单（发布前强制自检）

> 违规内容不进推荐池，重则删文、扣信用分、限制功能甚至封号。本文件汇总发布前必须逐条核对的红线。

## 一、广告法红线（行政处罚级）

1. **绝对化极限词禁用**：最、最佳、第一、顶级、国家级、100%、全网最低、零风险、治愈率 100% 等（可改用事实表述：「我们服务过 3000+ 客户」）。
2. **软文必须标「广告」**：《广告法》第 14 条要求广告具有可识别性；公众号带货/推广图文即使是「原创干货」，只要是商业推广就应在显著位置标「广告」。暗广夹带、软文不标是被处罚高发点。
3. **虚假宣传禁用**：无事实依据的功效、成分、销量、资质不可宣称。
4. **垂类专条**：
   - 健康/养生：不得宣称疾病治疗疗效，不得传未经证实的偏方（第 16/17 条）
   - 财经：不得承诺「保本」「稳赚不赔」，无资质不得荐股（第 25 条）
   - 教育：不得「包过」「包就业」

## 二、微信公众平台运营规范（平台处置级）

1. **诱导分享/诱导关注**：集赞、转发可见、关注领取、分享抽奖等 → 删文/封号高发区。
2. **标题党**：「震惊体」「不看后悔」「速看」「10 万+ 已删」、标题与正文严重不符 → 限流/删文/扣信用分。标题应如实概括正文核心。
3. **谣言与不实信息**：捏造/扭曲事实博眼球、传未经证实信息 → 严处。
4. **洗稿抄袭/侵权**：盗版、抄袭、仿冒大 IP 品牌误导用户 → 侵权处罚。
5. **违法违规内容**：色情、暴力、赌博、欺诈等 → 直接封号。

## 三、导流限流红线（2026 重点打击）

平台明确：导流会影响用户获得完整信息，可能带来欺诈/交易纠纷，不适合推荐。三类导流动作会限流：

1. **内容导流**：发布不完整内容后，通过二维码/文字/链接/图标引导用户跳转（其他公众号、小程序、视频号、第三方网页）。
2. **互动导流**：在简介、正文、评论、自动回复里嵌入微信号、二维码、外部链接，把人带出平台。
3. **多重嵌套导流**：定向引流+多重跳转（A 号引到 B 号再引导交易）规避检测。

写作对策：内容信息要完整自足；确需留联系方式时放菜单栏或合规位置，不在正文制造「去别处才能看到答案」的残缺感。

## 四、AI 内容规范（2026 新增重点）

1. 低质 AI 生成内容会被识别并限流 → 必须真人化：加真实经历、个人观点、具体细节。
2. 禁止 AI「魔改」经典影视/历史名人/动画形象做低俗化改编（微信珊瑚安全持续专项治理，2026 年 8 月单月处置违规内容 2633 条）。
3. 内容必须原创（原创权重约转载 3 倍；转载非原创不进公域推荐池）。

## 五、发布前 30 秒自检清单

- [ ] 全文扫描：无「最/第一/100%/国家级/保本/稳赚/包过/根治/治愈」等违规词？
- [ ] 商业推广是否已标「广告」？
- [ ] 标题与正文一致、无震惊体/夸大？
- [ ] 无诱导分享/关注/集赞话术？
- [ ] 正文无微信号/二维码/外链把人带出平台？
- [ ] 健康/财经/教育垂类是否越界？
- [ ] AI 味是否已清除（口语化+真实细节+个人经历）？
- [ ] 事实与数据是否可溯源、非捏造？

任一「否」→ 必须修改后才能交付。
