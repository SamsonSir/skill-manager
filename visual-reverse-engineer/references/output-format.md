# 输出格式

## 四种输出模式

| 模式 | 触发 | 输出 |
| --- | --- | --- |
| 图片模式 | 素材是图片 | 4 个区块 |
| 视频模式 | 素材是视频 | 11 个区块 |
| 只要提示词 | 用户说「只要提示词」「不用分析」 | 2 个区块 |
| 对比模式 | 用户给了多张图要对比 | 逐图分析 + 对比表 + 融合 Prompt |

---

## 图片模式

```
【视觉分析】
【VISUAL DNA】
【图片 Prompt】
【Negative Prompt】
```

---

## 视频模式

```
【视觉分析】
【VISUAL DNA】

【环境运动】
【摄影机运镜】
【焦点变化】
【镜头节奏】
【时间轴】
【连续性锁定】
【视频 Prompt】
【Negative Prompt】
```

## 「只要提示词」模式

用户明确说「只要提示词」「不用分析」「直接给 Prompt」时：

```
【图片 Prompt】
<一段完整英文 Prompt>

【Negative Prompt】
<负面词串>
```

**规则**：
- 跳过全部分析区块
- 不加任何解释、不加"以下是为您生成的"这类话
- 只给可复制的成品
- 如果开了 REFERENCE LOCK MODE，在 Prompt 里内嵌锁定声明，而不是单独输出锁定清单

---

## 对比模式

用户给多张参考图时：

```markdown
【参考图对比】

| 维度 | 图 A | 图 B | 图 C |
| --- | --- | --- | --- |
| 人物 | ... | ... | ... |
| 构图 | ... | ... | ... |
| 镜头 | ... | ... | ... |
| 光线 | ... | ... | ... |
| 色彩 | ... | ... | ... |

【融合建议】
人物取图 A，场景取图 B，光线取图 C。
<说明为什么这样组合，以及可能的冲突点>

【融合 Prompt】
<一段完整英文 Prompt>
```

**逐项指定来源**，不要混合成一张不存在的图。

---

## 语言规则

| 区块 | 语言 |
| --- | --- |
| 【视觉分析】 | 中文 |
| 【VISUAL DNA】 | 中文，字段值可中英混排 |
| 动作/运镜/时间轴/连续性等分析区块 | 中文 |
| 【图片 Prompt】/【视频 Prompt】 | **英文** |
| 【Negative Prompt】 | **英文**（纯中文模型可改中文） |

Prompt 用英文的原因：摄影术语的英文表达更精确，模型响应更稳定。

---

## 排版规则

**Prompt 写成一段，不分行、不用 bullet。** 分行会被部分模型当作多条独立提示解析，破坏权重。

分析区块用紧凑列表，方便用户逐项核对。

---

## 输出纪律

- [ ] 先分析后生成，DNA 在 Prompt 之前
- [ ] 每一项分析都标了 `[observed]` 或 `[inferred]`
- [ ] 不可测参数（焦段/光圈/灯位）全部标 `[inferred]`
- [ ] 视频模式的时间轴秒数连续且加总正确
- [ ] 视频模式声明了连续性锁定
- [ ] Negative Prompt 按实际风险点生成，不是固定串
- [ ] 「只要提示词」模式下没有多余分析
- [ ] 没有"我为你分析了……"这类说明性文字

---

## 用户追问时的处理

| 用户问 | 回答方式 |
| --- | --- |
| 「为什么是 85mm？」 | 给出推测依据（透视压缩、背景虚化程度） |
| 「能不能更像一点？」 | 检查一致性优先级前四项，指出具体哪项偏了 |
| 「换成 XX 风格」 | 说明会连带影响哪些项，给出建议 |
| 「这是用什么软件做的？」 | 明确说这是推测，不能确定，给出可能范围 |
| 「参数能确定吗？」 | 诚实说明单张画面无法反推精确参数，只能给区间 |

**永远不要在参数上装作确定。** 用户拿去复现失败时，诚实比自信有用。
