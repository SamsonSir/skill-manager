# 视频模式

在图片模式的全部内容之上，**增加七个视频专属区块**。

输出结构：

```
【视觉分析】        ← 同图片模式
【VISUAL DNA】      ← 同图片模式
【人物动作】        ← 新增
【环境运动】        ← 新增
【摄影机运镜】      ← 新增
【焦点变化】        ← 新增
【镜头节奏】        ← 新增
【时间轴】          ← 新增
【连续性锁定】      ← 新增
【视频 Prompt】
【Negative Prompt】
```

---

## 【人物动作】

拆解每个人物的动作，写成**动作链**，不是动作名称。

```
原因 → 准备 → 动作 → 接触 → 反馈 → 结果
```

| 项 | 内容 |
| --- | --- |
| 动作主体 | 谁在做 |
| 起止状态 | 从什么姿态到什么姿态 |
| 动作分段 | 按上面的六段链拆 |
| 速度 | 快/慢/匀速/加速/骤停 |
| 幅度 | 局部微动 / 全身位移 |
| 接触点 | 与什么物体接触，接触后发生了什么 |

**必须写出「准备」与「反馈」**——这两段是 AI 视频最容易丢、也最影响真实感的。

```
[observed] 她右手从口袋抽出，抬起至胸前高度，手掌转向门把，
           指尖接触金属，门把转动约 30°，身体被门带向前半步
[inferred] 动作总时长约 1.2 秒，起手略慢，接触瞬间加速
```

---

## 【环境运动】

画面中**非人物**的一切运动。

| 类别 | 检查项 |
| --- | --- |
| 天气 | 雨/雪/雾/风的强度与方向 |
| 光线 | 光斑移动、云影掠过、闪烁光源 |
| 植被 | 枝叶摆动方向与幅度 |
| 水体 | 波纹、倒影破碎、水流方向 |
| 烟尘 | 烟雾/灰尘/蒸汽的流动方向与速度 |
| 织物 | 旗帜、窗帘、晾晒衣物的飘动 |
| 人群车流 | 背景中的运动虚影与方向 |

**环境运动决定画面"活不活"。** 只写人物动作不写环境，成片会像静止背景贴了个动的人。

---

## 【摄影机运镜】

| 项 | 选项 |
| --- | --- |
| 运动类型 | 固定 / 推进 Dolly In / 拉远 Dolly Out / 横移 Truck / 升降 Crane / 跟拍 Tracking / 环绕 Orbit / 手持 Handheld / 航拍 Drone |
| 运动方向 | 左/右/上/下/前/后/旋转 |
| 速度 | 极缓 / 缓 / 中 / 快 |
| 稳定性 | 稳定器 / 轻微手持 / 剧烈手持 |
| 轴线 | 是否越轴 |

**运镜必须服务内容。** 说不出为什么这样运的，就写固定机位。

```
[observed] 镜头缓慢推进，从全景推到中景
[inferred] 推进速度约每秒画面宽度的 3%，全程稳定无晃动
```

---

## 【焦点变化】

| 项 | 内容 |
| --- | --- |
| 初始焦点 | 开场对在哪 |
| 变焦过程 | 焦点从 A 移到 B 的时机与方式 |
| 跟焦 | 主体移动时是否跟焦 |
| 拉焦 | 是否做焦点转移（Rack Focus） |
| 景深变化 | 全程恒定还是变化 |

```
[observed] 焦点始终在人物面部
[inferred] 无明显的拉焦动作，景深全程恒定
```

---

## 【镜头节奏】

| 项 | 内容 |
| --- | --- |
| 镜头数量 | 单镜到底 / 多镜切换 |
| 单镜时长 | 每镜几秒 |
| 切换方式 | 硬切 / 叠化 / 遮挡 / 匹配剪辑 |
| 节奏曲线 | 匀速 / 渐快 / 骤停 |
| 情绪节拍 | 哪一镜是高点 |

---

## 【时间轴】

按秒切分，标注每一段的内容。

```markdown
【时间轴】

0.0–1.5s   全景固定机位，人物从画面右侧走入，雨幕被逆光打亮
1.5–3.0s   镜头开始缓慢推进，人物抬头
3.0–4.5s   推到中景，焦点跟至面部，她停下脚步
4.5–6.0s   手持轻微晃动，她低头看手机，动作放缓
6.0–7.5s   镜头静止，她转身，画面留白扩大
7.5–8.0s   淡出
```

**规则**：秒数必须连续、加总等于素材时长。有跳跃或空白就是漏分析。

## 【连续性锁定】

**这是视频模式最关键的一块。** 列出全片必须保持不变的所有项：

```markdown
【连续性锁定】

人物身份   脸型、五官、年龄感、肤色 —— 全片不得变化
发型       低马尾，两颊湿发贴脸 —— 不得变化
服装       深墨绿防水风衣 + 米白高领 —— 不得换装、不得增减件数
饰品       左手腕细银表 —— 不得消失
道具       保温箱 —— 全程在手，不得凭空消失
环境       夜间暴雨窄巷，积水没过脚踝
空间关系   人物始终在巷子中轴偏右
光线       单一暖橙路灯光源，方向固定为画面右侧后方
天气       全程暴雨，不得转晴
时间       全程夜晚

状态继承
  第 1 镜淋雨 → 后续镜头风衣保持湿透且颜色加深
  第 3 镜保温箱外壁沾水 → 后续镜头保持水痕
  第 4 镜门被推开 → 保持敞开状态至镜头结束
```

### 明确禁止

变脸 · 变装 · 肢体畸变 · 道具消失 · 背景跳变 · 人物数量变化 · AI 感（塑料皮肤、无意义漂移、形变）

这些禁止项要同时写进 Negative Prompt。

## 【视频 Prompt】

**用英文书写**，一段，按这个顺序：

```
[画质与风格] + [主体] + [造型] + [动作] + [场景] + [空间层次] + [构图]
+ [机位与运镜] + [镜头与景深] + [焦点] + [光线] + [色彩] + [材质]
+ [环境运动] + [节奏] + [连续性声明] + [画质词]
```

末尾附加参数：

```
--ar 9:16 --duration 8s --motion 5        (视模型而定)
```

### 目标模型适配

| 模型 | 偏好写法 |
| --- | --- |
| Seedance | 分镜式，逐镜描述，重连续性声明 |
| Kling | 动作描述细致，重物理反馈 |
| Runway | 简洁，重运镜与风格词 |
| 豆包 | 中文可接受，重场景与氛围 |
| 通用 | 英文 + 明确运镜术语 + 连续性声明 |

不确定模型时用**通用写法**：英文、一段、运镜术语明确、连续性写在最后。

## 常见错误

| 错误 | 后果 | 修正 |
| --- | --- | --- |
| 只写人物动作不写环境运动 | 成片像静止背景贴了个动的人 | 环境运动单列一块 |
| 没写连续性锁定 | 第二镜就换脸换装 | 逐项列出锁定清单 |
| 时间轴秒数对不上 | 节奏失控 | 加总校验等于素材时长 |
| 动作只写名称不写六段链 | 动作生硬、缺反馈 | 至少写出准备与反馈 |
| 运镜堆砌炫技 | 与内容无关 | 说不出理由就用固定机位 |
| 禁止项只写"不要 AI 感" | 模型不理解 | 拆成具体项：变脸/变装/道具消失 |
