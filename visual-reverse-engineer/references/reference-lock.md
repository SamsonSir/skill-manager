# REFERENCE LOCK MODE

## 触发条件

用户说以下任意一种时开启：

- 「尽可能一模一样」
- 「完全还原」「精准复刻」
- 「不要改任何东西，只改 X」
- 「保持原样」

## 锁定清单

开启后，以下十项**全部锁定**，除用户明确指定要改的以外一律不得变动：

| # | 锁定项 | 锁定内容 |
| --- | --- | --- |
| 1 | 人物 | 脸型、五官、年龄感、肤色、发型发色、体型 |
| 2 | 服装 | 件数、类型、颜色、材质、穿着方式 |
| 3 | 姿态 | 身体朝向、脊柱曲线、头部角度、手部位置 |
| 4 | 场景 | 场所、建筑结构、天气、时代 |
| 5 | 构图 | 构图法、主体位置与占比、画幅、留白 |
| 6 | 镜头 | 机位、焦段、景深、透视 |
| 7 | 光线 | 光位、光质、色温、反差、阴影方向 |
| 8 | 色彩 | 主调、辅助色、点缀色、饱和度、分级风格 |
| 9 | 材质 | 皮肤、织物、金属、环境材质的观感 |
| 10 | 风格 | 摄影风格、年代感、后期质感 |

**只改变用户指定的内容，其余九项逐字保留。**

---

## 执行流程

**Step 1 — 确认改动范围**

明确用户要改哪一项。如果用户说得模糊（例如"改得更好看一点"），**先问清具体改什么**，不要自己猜。

**Step 2 — 生成锁定声明**

在 Prompt 前先输出锁定清单，让用户确认理解一致：

```markdown
【REFERENCE LOCK MODE 已开启】

锁定：人物 / 服装 / 姿态 / 场景 / 构图 / 镜头 / 光线 / 色彩 / 材质 / 风格
改动：仅 <用户指定的项>

影响范围：<说明改动会连带影响哪些项，以及如何处理>
```

**Step 3 — 处理连带影响**

改动某一项时，相关项会连带变化，必须显式说明：

| 改动 | 连带影响 | 处理方式 |
| --- | --- | --- |
| 换服装 | 色彩（新服装带来新颜色）、材质 | 保留原色彩基调，只让服装颜色落在同一色域内 |
| 换场景 | 光线（新场景的光源不同）、空间关系 | 尽量复刻原光位方向与色温 |
| 换姿势 | 构图（主体占比重算） | 保持主体位置与占比不变 |
| 换光线 | 阴影、色彩、材质观感 | 只改光，其余按原样 |
| 换时间（白天→夜） | 光线、色彩、场景细节 | 保留构图与镜头完全不变 |

**Step 4 — 生成 Prompt**

在 Prompt 里**显式写出锁定声明**，例如：

```
maintaining identical facial features, identical hairstyle, identical outfit,
identical composition and camera angle as the reference
```

不要指望模型自己记住。每一段都要声明。

**Step 5 — 锁定专用 Negative Prompt**

追加：

```
no face change, no hairstyle change, no outfit change, no identity drift,
no composition shift, no camera angle change, no lighting change,
no color grading change, no style drift
```

## 锁定强度分级

用户没说要"一模一样"时，按需求给不同强度：

| 级别 | 场景 | 做法 |
| --- | --- | --- |
| **全锁** | 「一模一样」 | 十项全锁，只改指定项 |
| **半锁** | 「保持这个风格」 | 锁人物、构图、镜头、光线；风格与色彩可调 |
| **弱锁** | 「参考这个感觉」 | 只锁风格方向与色彩基调，其余自由 |
| **不锁** | 「用这张图当灵感」 | 只提取 VISUAL DNA，完全重新生成 |

**默认级别是半锁。** 用户没说时不要自作主张开全锁，也不要完全不锁。

## 常见问题

**用户要改的项与锁定项冲突怎么办？**

例如用户要"换服装"但服装在锁定清单里——以用户的明确要求为准，但要提示连带影响：

> 换服装会让画面色彩关系变化（原图服装的深墨绿是画面唯一冷色锚点）。建议新服装保留同色域，否则整体分级会被破坏。要保留还是放开？

**用户要改的项会让画面"不像"了怎么办？**

明确告知，让用户决定。不要默默照做，也不要默默拒绝。

**参考图有多张且互相冲突怎么办？**

逐项指定来源：

> 人物取图 A，场景取图 B，光线取图 A，色彩取图 B。

并在 Prompt 里写明每部分的来源。不要混合成一张不存在的图。
