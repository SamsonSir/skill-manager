
## 【视觉分析】

按 23 个维度逐项输出，**带上 `[observed]` / `[inferred]` 标注**。

不要写成散文。用紧凑的分项列表，方便用户核对。

```markdown
【视觉分析】

主体      [observed] 女性，单人，画面唯一焦点
身份      [observed] 20 代后半，东亚面孔，身形偏瘦
五官      [observed] 鹅蛋脸，下颌线清晰，丹凤眼，鼻梁挺直，唇形偏薄
发型      [observed] 黑色齐肩发，低马尾，两颊有贴脸湿发
服装      [observed] 深墨绿防水风衣，米白高领针织，深色直筒裤
姿态      [observed] 侧身 3/4 朝向镜头，重心偏后脚，肩线向右下倾斜
动作      [observed] 抬头望向画面右侧，右手插兜
场景      [observed] 夜间窄巷，暴雨，积水没过脚踝
前中后景  [observed] 前景：虚化雨滴与栏杆 / 中景：人物与积水 / 背景：模糊的霓虹招牌
空间关系  [observed] 人物占画面右三分点，左侧留白朝向视线方向
构图      [observed] 三分构图，主体约占画面高度 55%
机位      [observed] 平视，约胸口高度，距离约 1.5m
焦段      [inferred] 85mm 左右 — 依据：面部无透视形变，背景压缩明显
景深      [observed] 眼睛锐利，耳后开始虚化
光圈      [inferred] f/2 附近 — 依据：景深过渡范围窄
光线      [observed] 侧逆光，暖橙路灯光从画面右侧后方来，冷蓝环境光补面
阴影      [observed] 硬边阴影，阴影内保留细节
材质      [observed] 皮肤有毛孔质感与鼻尖冷红，风衣为哑光防水面料
色彩      [observed] 冷蓝灰主调 + 暖橙点光，青橙分级
风格      [observed] 电影剧照质感，当代写实
后期      [inferred] 轻颗粒，暖部有轻微光晕，无磨皮痕迹
画幅      [observed] 2:3 竖版
```

## 【图片 Prompt】

**用英文书写。** 字段顺序固定，写成一段，不换行、不用 bullet。

```
[画质与风格] + [主体] + [造型] + [姿态动作] + [场景] + [空间层次]
+ [构图] + [镜头] + [光线] + [色彩] + [材质] + [后期]
```

### 写法规则

| 规则 | 说明 |
| --- | --- |
| 一段到底 | 分行会被部分模型当作多条提示解析 |
| 具体优先 | `warm ivory skin with visible pores` 优于 `nice skin` |
| 不用空词 | 禁止 beautiful / stunning / masterpiece / best quality |
| 推测用约数 | `around f/2`、`approximately 85mm` |
| 顺序即权重 | 越靠前权重越高，把最重要的放前面 |

### 末尾附加画幅

```
--ar 2:3 --style raw --v 6.1      (Midjourney)
aspect ratio 2:3                   (通用写法)
```

## 【Negative Prompt】

**必须根据参考图实际情况生成**，不要套固定词串。

生成流程：

1. 列出参考图里**实际存在**的高风险元素（手、脸、文字、镜面、多人、动物、车辆……）
2. 为每个风险元素生成对应负面词
3. 追加基础质量负面词
4. 检查是否有与正向词冲突的项（例如正向写了 `shallow depth of field`，就不要写 `blurry background`）

详细规则与词库见 `references/negative-prompt.md`。

## 一致性调整场景

用户要求"基于这张图改 X"时的处理：

| 用户要求 | 锁定 | 可变 |
| --- | --- | --- |
| 换服装 | 人物、构图、空间、镜头、光线 | 服装、材质、色彩（随服装变） |
| 换场景 | 人物、构图、镜头 | 场景、空间、光线（随场景变） |
| 换姿势 | 人物、场景、构图、镜头、光线 | 姿态动作 |
| 换光线 | 人物、构图、空间、镜头 | 光线、阴影、色彩 |
| 换风格 | 人物、构图、空间、镜头、光线 | 后期、色彩分级、材质观感 |

**换任何东西时，一致性优先级前四项都必须守住。** 见 `references/visual-dna.md`。

## 常见错误

| 错误 | 后果 | 修正 |
| --- | --- | --- |
| 焦段写成确定值 | 用户按错误参数复现不出来 | 标 `[inferred]`，用约数 |
| 五官描述笼统 | 换脸 | 写到能凭文字画出同一张脸 |
| 只写主体不写背景 | 画面扁平、背景随机 | 前中后景三层都写 |
| 光位只写"侧光" | 光从哪来随机 | 写方向：from camera left |
| Negative 用通用词串 | 该防的没防 | 按参考图实际风险点生成 |
| 直接输出 Prompt 无分析 | 用户无法核对与微调 | 先出 DNA |
