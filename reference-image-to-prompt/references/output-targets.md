# 输出格式与目标工具

共同原则：只改变表达方式，不改参考图事实。不承诺支持某个未核实的新型号或参数；未指定版本时不用猜版本号。用户只要结果就不附教程。

## 通用、GPT Image、豆包或即梦

使用中文自然语言说明主体、空间关系、画面风格与文字。需要避免的内容写成有关联的自然语言约束，例如“保持纯色背景，不添加其他物件”。不默认附独立 Negative Prompt、权重括号或命令行参数。用户指明的界面、模型或语法与默认不同则以用户信息为准，不把这里视为各平台所有版本的 API 规格。

## Midjourney

用户要求 Midjourney 时可给自然语言主体提示词。尺寸明确且比例可确认时可附 `--ar 宽:高`；没有可靠尺寸就只描述横竖幅或近似比例。仅使用已确认适用于用户版本的参数，不猜 `--v`、seed、权重与高级参数。不因工具改变而删除中文原文。

## SD / SDXL

按用户要求给 Positive / Negative 两段；Negative 只列当前图容易偏离的内容，例如扁平图标的写实摄影、立体反光、多余物体。不要为含字海报机械加入 text、letters 等与保留文字冲突的词。不虚构模型、LoRA、采样器、步数、CFG 或 seed。用户自己提供的配置可沿用。

## FLUX 或其他工具

默认自然语言提示词，不机械搬用 SD 的权重与负向词。用户明确给出可用输入字段或要求某种格式时按该格式输出；参数能力需另行核实，不声称通用于全部版本。

## 英文与 JSON（仅按需）

英文版本保留与中文相同的主体数量、位置、主色和文字，引用的中文文字不翻译。

用户只要求 JSON 时，仅输出合法 JSON，不加 Markdown 围栏。字段名使用下列英文名，字段值可以中文；未知值用 null 或空数组，不写貌似确定的占位事实。除用户指定其他结构外使用：

```json
{
  "medium": "平面海报",
  "aspect_ratio": null,
  "anchors": ["奶油色背景，顶部红色大标题"],
  "subjects": [{"description": "绿色瓶子", "count": 1, "position": "下半部中央"}],
  "texts": [{"content": "新品上市", "position": "顶部", "legibility": "clear"}],
  "palette": ["奶油色", "红色", "绿色"],
  "prompt": "以图片实际内容重建的提示词",
  "uncertainties": []
}
```

这是输出约定和示例，不是假称已执行的程序校验器。texts.legibility 使用 clear 或 partial；部分可读时 content 仅写确认的连续片段或 null，缺字记录到 uncertainties，不拼凑新文案。aspect_ratio 只有在可靠宽高信息可得时才写比例字符串。
