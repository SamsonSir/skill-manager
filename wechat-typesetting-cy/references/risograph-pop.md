# risograph-pop 风格规范（双色 tonal 老报纸版）

## 视觉定位

奶油纸底 + 深棕油墨 + 砖红点睛。**双色 tonal**，绝不超过两种强调色。复古印刷品 / 老报纸 / 文化杂志感。

## 适合内容

- 现象解读、文化类、有温度的长文
- 周末长读、历史类话题
- 需要"质感"和"沉浸感"的文章
- 不适合：纯技术教程（用 mono-terminal 或 notion-clean）、产品发布会风（用 dark-tech）

## 配色（仅 4 个色，含背景）

| 用途 | 色值 | 角色 |
|------|------|------|
| 主背景 奶油纸 | `#FBF7EC` | 整体底色 |
| 主文字 深棕油墨 | `#3D2817` | 标题、正文、深色块、描边 |
| 主强调 砖红 | `#C84B31` | 点睛色，标题装饰、引言点缀、CTA、大数字 |
| 次要文字 中棕 | `#6B5440` | 副标题、说明文字、署名 |
| 浅边线 米灰 | `#E8DFC9` | 列表分隔线（克制的过渡色，不是第 5 色） |

> **绝不要**引入第三个强调色。任何"再加一个绿色试试"的冲动都要忍住。双色 tonal 的灵魂就是克制。

## 字体（双字体策略）

**标题用衬线**（老报纸大字标题感）：
```
font-family: Georgia, 'Songti SC', 'STSong', serif;
```

**正文用无衬线**（系统字体易读）：
```
font-family: -apple-system, 'Helvetica Neue', 'PingFang SC', sans-serif;
```

**斜体的用法**：所有大数字编号（01/02/03）和大引言金句用 `font-style: italic`，制造手写印刷物的味道。

## 组件清单

| 组件 | 说明 |
|------|------|
| Banner | 砖红 ISSUE/期号 + 中棕日期分行 + 双行大标题（一行深棕一行砖红斜体）+ 中棕副标题 |
| 双线分隔（刊头） | 4px 深棕粗线 + 2px 奶油空白 + 1px 砖红细线，制造老报纸刊头分隔感 |
| 章节头 | `§ 01 · SECTION` 砖红装饰符 + 深棕衬线大标题 |

| 引言区 | 深棕底 + 上下砖红 3px 装饰线 + 顶部砖红大引号 + 奶油色斜体衬线金句 + 砖红署名右对齐 |

## 微信适配硬约束

- 主布局 `<table border-collapse: collapse>`
- 所有 `<td>` 加 `border: none`（数据格的边框单独写在 `<table>` 上）
- 背景全部实色 hex
- 不用 `flex / gap / linear-gradient / background-image / @font-face`
- 大引号 `&ldquo;` 用 `<span>` 包裹设置颜色，不要用 `::before`
- 衬线字体在移动端会回退到 Songti SC（macOS）/ STSong（系统宋体），效果稳定
- 双线分隔用 3 个 `<tr><td>` 横条，每条 1-4px

## 排版小诀窍

- **斜体只给数字和金句用**，不要给章节标题用（章节标题用斜体会变软）
- **双色之间留呼吸**：如果一段同时出现深棕加粗和砖红加粗，把砖红那个挪到下一段
- **大色块的两种姿态**：
  - 深棕底 + 砖红装饰线（引言区）→ 深沉感
  - 砖红底 + 双线奶油描边（标语板）→ 印章感
- **数据格中间格反色**是这个版本的关键设计——三格里中间一格用深棕底，避免三格全奶油底显得平
- **不要用阴影**（`box-shadow`），全靠颜色和描边出层次

## 与其他模板的差异

- 跟旧版 risograph-pop（三色波普）：色数从 5 砍到 4，砍掉亮黄品蓝，加深棕做主油墨
- 跟 `dark-tech`：dark-tech 是黑底科技产品风，risograph-pop 是奶油纸文化复古风
- 跟 `blue-minimal`：blue-minimal 是蓝色现代杂志感，risograph-pop 是棕红老印刷品感
- 跟 `notion-clean`：notion-clean 是工具白底极简，risograph-pop 是质感纸底沉浸
- 跟 `mono-terminal`：完全相反方向，一个等宽 hacker，一个衬线印刷物
