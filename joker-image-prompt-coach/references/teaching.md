# 教学索引与示例

教材：https://developers.openai.com/api/docs/guides/image-prompting
核对日期：2026-09-13。下列顺序与练习为本技能的教学设计，不是官方规定课程。

## 章节与学习路径

按官方页面章节标题定位，避免依赖易变行号。

| 建议学习点 | 官方章节 | 练习目标 |
| --- | --- | --- |
| 意图与表达是否足够 | Prompting fundamentals | 说出当前最想控制的画面特征，保留自由发挥空间 |
| 主体、用途与构图 | Prompting fundamentals | 用少量位置或景别描述解决一个具体布局问题 |
| 可见细节与风格 | Prompting fundamentals；Control style and lighting | 区分感受与视觉选择，解释所补条件的作用 |
| 人物动作与关系 | Prompting fundamentals | 清楚表达目光、动作或物体间关系 |
| 画面文字 | Render exact text | 识别文字原文、次数和位置等可控制条件 |
| 参考与局部编辑 | Assign roles to references（fundamentals 内）；Transfer a visual style；Remove an object | 分清参考用途、修改项与保留项 |
| 迭代与验收 | Iterate deliberately（fundamentals 内）；Check the result | 从图片指出一个偏差，选择一次有针对性的修改 |

依据摘要：明确用途、构图及必要细节；格式以易读为准。文字写清原文；参考图注明用途；编辑区分改变与保留。逐项迭代并检查结果。参数独立于提示词，反复编辑仍可能漂移。完整解释以官方对应章节为准。

参数选择、透明背景、产品或科学图等专题在实际需要时读取官方对应段落，不作为入门门槛。不固化模型名称、价格或参数表。

## 示例 A：短描述本来就足够

用户：“画一只在窗边睡觉的橘猫，我没有其他要求。这样写可以吗？”

教学示范（原创）：可以。这句话已经给出了主体、位置和动作，其余细节可留给模型决定。联系官方关于表达格式的原则，说明无需为了专业感加长。如果后面发现猫太小，而你希望突出猫，才举例增加“近景，猫占画面主要部分”。解释新增句仅用于控制主体大小；不是原句不合格，也不保证一次就完全解决。

可选练习：用户若想保留更多窗外环境，会怎样调整构图要求？不要同时添加季节、镜头和毛发材质。

## 示例 B：感受词与编辑意图

用户：“年轻一点、风韵犹存、我见犹怜。”

教学示范（原创）：这传达了感受，可以结合上下文使用。先看是否已有原图与编辑任务；不要重复询问已知信息，也不要断言必须提供参考图。说明若希望更精确控制，需要区分希望改变的部分与保持的部分；没有目标图时不能假称看过。

假设示例：仅为了演示编辑原则，假设用户补充“我想减轻原图中的疲惫感，但保持同一个人”。示例句：“基于这张头像减轻疲惫感，保留人物五官特征、发型和原有画风。”

解释：前半句表达调整方向，后半句划定保留范围。仍保留一定视觉自由度；只有实际结果偏离用户意图，才进一步讨论哪个可见细节需要控制。该示例不是官方对“风韵犹存”的解释，也没有替用户确定年龄、服装或性格。

## 示例 C：文字位置

用户已有要求：“做一张海报，写周末读书会，其他随意。”随后反馈：“标题太靠下，我要放上面。”

教学示例（原创）：“标题文字为‘周末读书会’，放在画面上方。”

解释：本次仅明确文字原文和位置；没有必要重写整幅画面的风格。如采用原图编辑，还需依据用户希望保留的内容表达保留项。让用户实际检查文字和位置，不能仅凭提示词宣称成功。

## 教练自检

给出教学回复前检查：是否能对应官方章节？示例假设是否明确？是否加入用户没要的设定？是否把可选条件变成必填项？是否解释关键句的作用？没有图时是否误称已验证？
