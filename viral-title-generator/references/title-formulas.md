# 爆款标题公式

本文件是标题生成的底层公式，一个主题可套多个公式产出不同角度。每个公式给「结构 + 示例」。

## 1. 数字清单

结构：「N 个 / N 步 / N 倍 + 结果/好处」

- 5 个让你加薪翻倍的职场习惯
- 3 步搞定周报，再也不用加班写
- 10 倍提升效率的 4 个工具

## 2. 悬念钩子

结构：「别再 / 居然 / 原来 / 这才是 / 为什么 + 反常识结论」

- 别再这样写简历了，HR 一看就扔
- 原来真正的自律不是靠坚持
- 这才是高效会议的真相

## 3. 反差对比

结构：「A 和 B 的差别 / A 与 B，差在 + 关键点」

- 月薪 3k 和 3w 的人，差在这 3 个思维
- 同样加班，为什么他升职你背锅
- 会做和不会做 PPT 的人，差距有多大

## 4. 痛点戳心

结构：「踩过的坑 / 没人告诉你 / 最怕 + 痛点场景」

- 租房踩过的 5 个坑，个个都是血泪
- 没人告诉你的 Excel 隐藏技巧
- 打工人最怕的 3 件事，你中了几个

## 5. 利益承诺

结构：「一招 / 直接抄 / 白嫖 / 立省 + 具体好处」

- 一招让你的简历通过率翻倍
- 这套模板直接抄，周报 5 分钟搞定
- 白嫖 3 个神器，上班摸鱼都更有底气

## 6. 热点借势

结构：「热点词 / 近期事件 + 你的主题切入」

- 都在讨论 AIGC，普通人怎么搭上车
- 看完《XXX》，我悟了这 3 个道理

## 7. 共鸣共情

结构：「是不是 / 有没有 / 你也是 + 普遍情绪」

- 是不是每次开会你都在假装认真
- 打工人的周一，从抗拒开始
- 有没有一种累，叫心累

## 8. 反常识颠覆

结构：「其实 / 真相是 / 越 X 越 Y + 颠覆认知」

- 越努力越平庸，问题出在哪
- 坚持早睡，其实是最低效的自律

## 组合使用

- 一个主题至少套 4 个公式，避免角度雷同。
- 好标题常是「公式叠加」：数字 + 痛点、反差 + 悬念。
- 每条标题产出后自查：是否真实对应内容？是否可兑现？
