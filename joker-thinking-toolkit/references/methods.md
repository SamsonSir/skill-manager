# 思考方法与边界

| 方法 | 触发信号 | 核心产出 |
|---|---|---|
| 问题澄清 | “我可能没说清楚”“到底该问什么” | 事实、解释、目标、假设和一个关键问题 |
| 双层解释 | “我完全不懂” | 日常解释、专业机制、边界和理解检查 |
| 反向拆解 | “这个为什么做得好” | 可迁移规律、不可迁移细节和练习 |
| 横纵分析 | “系统研究一下” | 时间线、同类对比、未来路径和证据 |
| 事实核查 | “靠谱吗”“是真的吗” | 事实等级、推理漏洞和可信程度 |
| 专家会诊 | “多角色对抗”“专家怎么看” | 互补视角、共识、分歧、假设和综合方案 |
| 第一性原理 | “从第一性原理看”“别打补丁” | 基本事实、未证假设、重新推导和验证动作 |
| 跨领域借解 | “常规办法都不行” | 异领域相似机制和可逆实验 |
| 双向钢人 | “两个方案选哪个” | 双方最强论证、关键变量和明确判断 |
| 最小实验 | “先试再说” | 待验证假设、指标、继续与停止条件 |
| 隐藏天赋 | “我真正擅长什么” | 基于具体经历的能力线索，不仓促贴标签 |
| 人生设计 | “我不知道自己想要什么” | 多条可体验的未来路径，不替用户决定 |

## 组合限制

- 默认一个主方法加最多一个辅助方法。
- 事实核查必须使用当前外部证据，不能用模型记忆给自己作证。
- 专家会诊使用专业视角，不模仿或编造真实人物观点。
- 自我探索采用多轮、一次一问，所有判断对应用户具体经历。
- 低风险简单任务不得进入复杂问诊或多视角流程。
