# Speaker Notes Checklist

## 整场
- [ ] 一句话说清主线
- [ ] 每页只有一个主要任务
- [ ] 无无意义重复页
- [ ] 核心案例时间多于过渡页
- [ ] 结尾回到听众可执行的下一步

## 每页口播
- [ ] 第一自然承接上一页
- [ ] 不逐字念屏幕
- [ ] 说明为什么值得看
- [ ] 长句已拆
- [ ] 抽象词能具体化时已具体化
- [ ] 不强行金句或每页升华
- [ ] 演讲者身份与事实一致

## 代入测试
- [ ] 你/它/我们指代明确
- [ ] 替换成真实对象后仍顺
- [ ] 会议室同事测试通过
- [ ] 一口气能说完
- [ ] 听众无需二次翻译抽象概念

## 事实
- [ ] 已完成 / 待验证 / 设想分开
- [ ] 示意数据明确
- [ ] 不把截图扩大成完整验收
- [ ] 不虚构原话、指标或效果

## 互动
- [ ] 问题具体
- [ ] 有停顿时间
- [ ] 有人/无人回答都有接法
- [ ] 互动能进入下一页

## 转场
- [ ] 不依赖“下面进入……”
- [ ] 由问题、差异、结果或普通口语引出
- [ ] 不为转场制造抽象概念

## 时间
- [ ] 视频按真实时长
- [ ] 互动留浮动
- [ ] 正文不排满全部时间
- [ ] 有可删减的非核心段落
