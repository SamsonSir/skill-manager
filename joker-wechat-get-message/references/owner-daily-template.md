# 多多群主日报模板（字段合同）

对照样本：群主 2026-09-08 日报 https://my.feishu.cn/docx/K4bSd2RHkoOxAaxZSuMc9xWWnKf  
标题：`2026-09-08-三十秒电影感视频提示词实战`

栏目顺序与本技能 `daily.py` 的 `BLOCKS` 相同。**差的不是栏目名，是每块要写什么。** 禁止另起第十套栏目。群人数/新增若快照没有可靠字段，明确不写，不要抄样本里的 392/21。

## 每块写什么

| 块 | 样本在写 | 禁止 |
|---|---|---|
| 🧭 一句话总览 | 一段话点出当天最有辨识度的一条线（谁、做了什么、带到哪） | 只报条数和 Top 发言人 |
| 📊 群聊数据 | 总数、活跃、覆盖时段、首末条 | 编造群人数、新增、运营天数 |
| 🏆 发言排行 Top 5 | 真实备注/昵称 + 条数 | `成员01`、wxid、把排名数字当人名 |
| 🔥 热议话题排行 | **事件名**（「家长把《三峡》课文做成AI短片」） | 关键词桶名反复出现（「提示词与参考图」×N） |
| 💡 重点讨论 | 每项三个字段，见下 | 把 20 分钟消息簇原话用分号拼起来 |
| 📌 关键进展 | 有结果的事：谁交出了什么、做到哪一步 | 「某某分享了 example.com」 |
| 💭 思考摘录 | 有判断的原话，保留人名 | 把提示词全文、街机分镜当思考 |
| 🧰 重点工具 / 资源 | 名称 + 当天怎么用 + 边界 + 链接 | 只丢原始 URL，或微信头像/收藏夹链接 |
| 🔖 关键词 | 当天事件与方法词 | 高频虚词、人名凑数 |
| 🖼️ 学习地图 | 指向本机学习地图；不要冒充群主长图 | 再画一张群聊流水长图 |

## 重点讨论三项（硬字段）

每条必须有独立事件标题，然后：

1. **发生了什么：** 叙事。时间、谁、做了什么、结果。不是聊天摘录拼接。
2. **群友可参考：** 可带走的做法或边界。必须能独立成句，例如「先用 15 秒试效果，避免一次烧光额度」。
3. **参与：** 真实备注/昵称。

禁止把「群友可参考」写成下面任何一句：

- 以上是该时段可读文字摘录，不是教程全文
- 附件未展开，练习前回到原消息上下文
- 本期未发现可整理内容（有讨论时）

没有可迁移做法时写清「该话题还停在晒图/询价，没有可复用步骤」，不要用套话凑字段。

## 脚本与 Agent

质量靠这份字段合同，不靠某个模型的文风。换 Grok / Codex / Claude 都走同一条路：

1. `daily.py` 只算：统计、排行、禁止编号/成员编码。
2. Agent 读当天聊天，把讨论填进 `scripts/overlays/YYYY-MM-DD-<群名>.json`。
3. `daily.py build --overlay … --publish` 或把文件放到默认路径后跑 `organize.py`。脚本会自动套 overlay。
4. **没有 overlay 不准写入飞书，也不发卡片。** 机械日报可以留在本机 XML 供填写，但不能覆盖 Wiki。

overlay JSON 形状：

```json
{
  "theme": "当天那条线的短标题",
  "overview": "一句话总览",
  "topics": [{"title": "事件名", "heat": 90}],
  "clusters": [
    {
      "title": "事件名",
      "count": 40,
      "start": "09:00",
      "end": "12:00",
      "names": ["真实备注"],
      "what": "发生了什么：叙事，不是摘录拼接",
      "takeaway": "群友可参考：可带走的做法"
    }
  ],
  "progress": ["有结果的事"],
  "thoughts": [{"name": "真实备注", "text": "有判断的原话"}],
  "tools": [{"label": "名称 · 当天怎么用", "url": "https://…"}],
  "keywords": ["事件或方法词"]
}
```

对照样本时核的是字段是否写满、事件是否独立，不是把群主原文整页搬进 Wiki。
