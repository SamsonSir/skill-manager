# 固定报告模板

默认分别输出多多、夙愿，禁止混为同一群。以暖米白背景、棕色标题区、白色圆角卡片、深色正文排版，信息层次参考用户提供的群日报长图。正文阅读优先，手机单列，桌面可用双列摘要。内容少就缩短，不为了版式凑Top数量。

## 模块与顺序

1. **日报/周报概览**：群名、用户请求区间、实际读取区间、数据最新时间、生成时间、核心摘要；滞后数据显著标为“历史快照/部分覆盖”。
2. **数据概况**：消息数、实际发言人数、分享条目数、最早/最晚发言时间。统计按所选范围计算；消息数含哪些类型注明。发言人数按非系统消息中已知sender_username去重，缺失者不编造。分享条目按消息计，不冒充独立资源数。没有可靠成员总数就不显示群人数、新增人数或活跃率。
3. **热门话题**：讨论热度和学习价值分列。热度按归属该话题的唯一消息身份数量；同一消息可以多主题，合计不等于群总数。学习价值为整理判断，不伪装统计。没有话题归属明细则只写“反复讨论”，不编热度数字。发言排行可放折叠次要区，默认匿名。
4. **重点讨论**：每项含“发生了什么／有用结论／不同意见或未解问题／怎么应用／来源”。长讨论用details折叠，标题与摘要在折叠外。
5. **干货与心得**：方法论、教程步骤、可复用提示词、实测经验、失败与调整。原话引用与改写模板区分；不能将转发文章标题扩写成完整教程。
6. **变现案例**：具体成果、需求方/客户类型、交付方式、金额口径、阶段、证据、可复用部分。未知写未知；无案例写未发现。变现专题将此模块置于重点讨论之前，并压缩无关模块。
7. **工具与资源**：名称、用途、原分享位置、链接、已读/仅标题/未验证。不要带出邀请链接、鉴权参数；不能安全清理的链接只留本机索引定位。
8. **我的行动清单**：只列少量从本期证据延伸、能完成的具体实践，明确为整理建议。没有足够材料则不强行推荐。

## HTML交互与来源

HTML为单文件，内嵌样式和少量脚本，关闭脚本仍能读正文。提供一个搜索框筛选话题/内容卡片；无匹配显示提示。用原生details展开正文，搜索命中折叠内容时应可展开看到。键盘能操作搜索和折叠；正文、表格在手机宽度不溢出。

来源索引可作为HTML末尾锚点，展示时间、匿名发送者、必要短摘录和消息定位。另存`来源索引.md`便于本机回查。把数据中的`<`、`>`、引号转义，链接限定http/https与本机已验证文件；不允许javascript或从聊天拷贝来的脚本。

## 精华长图

每群一张，沿用报告主题和配色，仅放真实关键内容，不把全部长报告塞入图中。顶部保留群名和实际数据区间，核心卡片放观点、方法或案例，页脚说明完整出处见HTML。无需固定高度或固定卡片数量。

使用内置imagegen；生成前提炼短版中文，剔除成员身份与私密材料。结果文字、群名、金额单位和阶段必须与HTML一致，尤其不能把预算画成利润。查看生成图后再交付；如果生成失败，保留HTML，标为部分完成，不提交本次游标。

## 验收

- 数据：群ID、时间范围、消息计数直接对照SQLite；发言人数、分享数有口径。
- 内容：核心引用能定位；多个发言人、项目不串；猜测、原话、转发、整理建议分明。
- HTML：实际用浏览器或可用本机浏览工具检查可读性、搜索一个有匹配词和无匹配词、展开折叠、窄屏布局。读取当前可用computer-use能力，不硬编码旧工具。
- 图片：查看实际生成图，检查标题、数字、主要文字和截断；记录工具返回真实路径。
- 文件：每群HTML、PNG、索引均存在非空；所有需要交付的文件成功才推进对应模式进度。
