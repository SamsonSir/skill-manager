# 本机 HTML 与学习地图

群和联系人分开输出，禁止混成同一份。

## 群：Wiki HTML

群的 HTML 是该群 Wiki 子树的**可交互阅读页**：侧栏分总览 / 日报 / 方法站 / 资源，主栏一次只读一页，能搜索。不要把全部页面糊成一篇公众号长文。

```bash
python3 "/Users/joker/.skills-manager/skills/joker-wechat-get-message/scripts/wiki_html.py" export --name 多多 --json
```

视觉走宝玉 **design** 的阅读器，不是 markdown-to-html 长文。实现是 `scripts/reader.py`：深色侧栏、浅色纸面、钨丝强调色；侧栏用短标题；可筛选日报/方法站/资源；主栏一次一页；日报把「群友可参考」做成深色卡片。双击可开、不依赖 CDN。不要调用 `baoyu-markdown-to-html`。

飞书日报九块仍由 `scripts/daily.py` 写进 Wiki；HTML 只是把 Wiki 已有正文转成本地可读页。

## 群：学习地图

图必须是学习路线图，版式对标首次整理的「AI视频学习地图 / 从复刻，到可控出片」：米白长图、01–07 方法站、底部收束句。内容从 Wiki 01–07 抽取，不把群聊流水、排行榜或日报九块画进图里。

`scripts/organize.py` 会在导出 Wiki 后生成 `学习地图.html` 和 `学习地图.png`。

## 联系人：对话复盘顺序

联系人不要套群热度榜和变现案例，除非用户这轮明确要变现。

1. **概览**：对方显示名、请求区间、实际读取区间、数据最新时间、核心摘要。
2. **数据概况**：消息数、双方发言条数口径、最早/最晚时间。
3. **重点往来**：按话题，不按逐条流水。谁说了什么要能定位。
4. **待跟进**：约定、未回、需要你做的事；没有则写未发现。
5. **干货与材料**：对方分享的方法、链接、文件入口；提取不到的附件只列入口。
6. **我的行动清单**：少量可执行项。
7. **来源索引**。

联系人 HTML 仍为单文件、内嵌样式；把数据中的 `<`、`>`、引号转义，链接限定 http/https。群 HTML 由宝玉生成，不要再塞搜索框或群友画像。

## 验收

- 群 HTML：能打开，含该群首页标题、01–07 站名和至少一篇日报短标题；能点侧栏换页、能搜索；打开一篇日报能立刻看到「群友可参考」卡片。不是公众号长文，也不是旧版棕色卡片或发黄手帐皮。
- 学习地图：PNG 上能读到「AI视频学习地图」和 01–07 标题，与 Wiki 方法站一致。
- 飞书卡片：Card 2.0，含九块日报信息，有打开 Wiki 的按钮。
- 联系人报告：核心引用能定位；多个发言人、项目不串。
- 失败保留有效产物，不把未验证的 HTML/图/卡片标成完成。
