# Grok Bot 例程粘贴稿

对负责情报的那只 Bot 说（或改现有「Grok原始情报包邮件处理」）：

```
每天 09:00（Asia/Shanghai）运行 X 情报早报。

1. 读 Gmail 近 24 小时主题含「原始情报包」的邮件作为原料。
2. 再用 X 搜索补全（List 优先）：发布、提示词、工具、工作流、爆款产品、Codex/Claude Code/Harness/Loop。
3. 按 skill x-daily-brief 输出六栏早报，各最多 3 条，推荐 100 分制，字段为关键 / 对你 / 来源。
4. 只在本对话推这一封。不要转发 AgentMail。不要写给 Hermes 的回信。不要发 X。
5. 读不到邮件就只靠 X 搜索，仍必须有可点链接。两边都失败则只发一行失败说明。
```

停用：HTML「关注流精读」；早读不再经 AgentMail/Hermes。
