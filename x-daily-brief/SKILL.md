# X 情报早报

人读唯一主交付。机读包是原料，不是给用户看的东西。

## 步骤

1. 取过去 24 小时原料，能拿多少拿多少：
   - Gmail 里主题含「原始情报包」的最近一封（若能读邮件）
   - X 搜索：关键词 + 语义 + List/Following；List 优先
   - 覆盖：重大发布、提示词、工具/开源、工作流、爆款产品、Codex/Claude Code/Harness/Loop、个人提及
2. 综合过滤。加权：AIGC / AI 自媒体 / AI 电商 / 方案交付 / Agent 工程为高；其它 AI 够新够大才留。
3. 只输出下面格式。聊天只推这一封。不发 X。不转到 AgentMail。不要解释过程。

## 输出

```
早报 YYYY-MM-DD
资讯n · 提示词n · 工具n · 工作流n · 产品n · 工程n

提及          ← 仅当有人点名 @super_supf / su Sun / Joker，最多2行
1. 核心资讯
2. 实用提示词
3. 开源与工具
4. 新工作流
5. 爆款产品
6. Agent 工程
```

- 六栏各最多 3 条。不够 3 条不凑。空栏整段删除。
- 推荐 0–100。低于 60 不出现。90–100 今天就看/装；75–89 值得试；60–74 可扫。
- 工具另标 装/试/过。
- 每条：标题（名字 · 推荐 xx/100）+ 关键 2–5 句 + 对你 2–5 句 + 来源（@作者 + https://x.com/... 或 GitHub）。
- 提示词：写能生成什么和槽位结构，不贴原文。
- 工作流：步骤可到 5 步，并写不适用。
- 禁止：赛道/竞品/钩子/趋势栏、HTML、大段提示词、加工过程、客套。
- 只报 24h 新东西；昨天同款无增量则跳过。
- 无原料时只写一行：`早报失败：近 24h 没有可验证来源`，不准用训练记忆填。

完整字段说明见知识库 `40_知识库/AI工程/X情报早报-人读格式.md`。
