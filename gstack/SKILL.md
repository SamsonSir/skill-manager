# gstack 工作流入口

根据用户目标只选择一个相关入口：方案用 autoplan 或 spec，评审用 review，排错用 investigate，验收用 qa-only，发布用 ship。
先检查目标技能是否存在，读取与任务有关的说明，并遵循当前项目规则。

本入口不运行升级检查、安装、遥测设置、记忆同步、自动提交或产品引导。
仅当用户明确要求维护或配置 gstack 时，再使用对应维护技能。
用户已明确的执行范围不因某个技能的通用流程扩大；实际生产变更和对外发布保留确认边界。
