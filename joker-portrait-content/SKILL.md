# 写真账号创作导演

把人物、动作和摄影设计组合为可执行的画面，再按目标账号文字方法制作内容。共享技能只存通用方法；人物资产、正文、状态和权限留在各账号。

## 先确定本次合同

1. 从对话确定目标账号；矩阵项目先读账号目录，再读该账号 AGENTS、配置、最新底座、当前进度、视觉配置、角色合同与文字教程。已有上下文明确的选择不重复询问。
2. 记录模式：提示词 / 封面 / 成篇 / 同组续图 / 完整宫格。写真账号封面默认一张独立候选；请求标题正文则按成篇模式。纯文字请求不生图。
3. 显式参数优先于账号补充值，账号决定优先于技能或路线默认。锁定年龄、身形、风格、场景、衣服、姿势、画幅、露脸、身份范围及交付终点，不固化上次试样参数。
4. 账号确实无法确定时才问账号。其他未知值依据账号方法补全，记录来源；后台未知不妨碍本地制作。

目标为photo-account-pending时，导演输入以本账号 `04-图片素材库/选辑视觉配置.json#visual_brief` 为准；每次读取当前视觉范围，不把历史臀部封面或某条路线的默认审美当成全部选择。其他账号不继承该范围。

## 三模块协作：导演统筹画面

先从人物模板、账号配置和用户指定姿势提取需要保留的条件，再让导演统筹整张画面；读取顺序不表示先替导演决定穿搭、发型或动作。未指定的字段由导演设计，不能把上一张参数或执行者随手选的方案登记为用户锁定。最终提示词仍采用用户确认的字段结构。

账号名称用于识别账号，不自动转译为人物职业、服装或场景。依据账号明确视觉目标与当次创作意图选择摄影路线；名称中的“下班”“写真馆”等字词不是路线锁定参数。生成前按下方参考核对摄影路线、空间类型、造型气质和动作的整体差异，不能仅靠换色或换发型判定变化。

新的一篇、新独立候选自动进入导演设计；无需用户补说“换装”“换发型”。同组续图、原图改比例或明确保留造型的编辑，继承对应连续性要求。具体比较与记录执行 [导演融合与输出](references/director-integration.md) 的“主动编排与近期比较”。

### 人物模板

读取 [人物模板](references/portrait-template.md)。完整保留人物与身形核心，不能仅用“健康匀称”或“丰腴”标签代替。明确成年，默认视觉年龄20—26岁；用户或目标账号有效修改仍优先。
不露脸时保留人物设定，不为展示五官加回眸或侧脸。朝向遮挡的部位记为本机位不可见，不能强行扭身展示全部线条，也不能因此改瘦身形。

### 姿势库

读取 [姿势与宫格](references/pose-library.md)。用户指定01—16时锁定支撑点、腿、躯干、朝向，导演只补细节，不换身体结构。未指定编号可设计库外站立、行走、坐姿、镜自拍等，明确是库外动作。
完整16宫格只在明确要求时启用；单张不带宫格边框、跨格背景或隐藏脸，不先做总览。第10姿势原文支撑解释缺口须说明，不冒称严格实现。

### 导演设计

读取 [导演融合与输出](references/director-integration.md)，再实际读取已安装 `female-portrait-director/SKILL.md`，按入口加载 canonical workflow、style-registry、唯一匹配路线及 director-gate，按需加载Overlay、参考图与相关核心规则。
导演须设计同一个可拍瞬间：主目标、轻微事件、重心动作链、发型与发色、服装剪裁/材质/配色、配饰、场景、摄影师或自拍关系、景别机位、光线落点和成像。人物模板提供身形核心，姿势库提供动作结构，导演选择未指定的组合并核对二者；瑜伽服不自动等于运动风，不把曲线路线永久锁为唯一风格。
依赖缺失时查找已安装位置或说明缺口；不能把未调用上游的拼词称为完整导演执行。本技能默认字段式，是对上游输出层的适配；用户指定其他格式时从其要求。摄影设计照常执行，不改上游技能。

## 实际生成与验收

1. 把账号当前面部策略写进 `面部呈现`（兼容原`露脸控制`字段），并在动作/机位/遮挡中落实。严格不露脸时，正脸、侧脸、回眸及反射内可辨认脸均不得出现；若当前账号或用户明确允许侧脸、仅要求正脸不清晰，则按该可见范围设计与验收，不把侧面轮廓判为失败。允许正脸可辨认的账号不得套旧不露脸默认，正脸、侧脸、背影、遮挡由当前摄影设计决定。手机遮脸自拍不自动改为背面。
2. 写最终字段提示词，逐项检查参数传递。正向与可选负面约束分开；保存本次实际提交的全部文本，交付提示词须与调用一致，不偷偷另写保守版本。
3. 要求生图时读取 `imagegen` 并用内置图像能力。新原创人物不绑定旧图主脸；项目图存目标账号，不覆盖历史。仅同组续图/指定保留身份时读取并传该组参考，核对归属。
4. 出图后实际查看当前面部呈现策略、年龄可见程度、身形比例、臀腿/腿部重点、动作支撑、手脚、衣料受力、构图和摄影真实感，并核对导演选择的穿搭、发型、动作与近期差异是否实际出现在图中；提示词写过不等于实图实现。将实际结果和候选状态写入本账号视觉记录。无脸不宣称实图确认精确年龄；编辑检查通过不等于用户满意或点击率验证。
5. 失败记真实状态。审核拒绝不换词规避，不用未同意替代画面冒充完成；技术问题可针对原因修复，保留实际文本与结果。

## 成篇模式

读取目标账号文字方法和原文锚点，调用 `joker-wechat-workflow` 文章制作阶段，账号有效范围和权限优先。按账号目标选题、写正文、定标题，不从图片编人物履历或亲历。
“写真封面＋生活文章”账号按当前文字教程选择题材、篇幅与推进，兑现标题；不改为臀部/服装/摄影教程，不强图文关联、三步或段数。只在账号明确采用时启用该打法。
本地成篇交付封面、实际提示词、标题、正文、纯正文HTML和预览；记录摘要、资产、来源和编辑检查。正文变更更新审核哈希。新原创组登记候选，无认可主脸时如实记冷启动，不伪造确认身份或一致性通过。
按本次终点停止。后台保存、发表、发送、定时器不从共享技能继承授权；本地预览不称后台草稿，未绑定照常完成本地成品。

## 对外交付

以图片、标题、正文和预览为主，附实际提示词与技能路径。仅提示词模式只交付字段。必要限制简短写明，不附内部推理、草稿历史、凭据或日志。
