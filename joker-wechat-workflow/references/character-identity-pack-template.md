# 固定人物视觉身份包模板

本模板用于账号已选择固定身份的角色；多人物原创选辑使用 visual-continuity.md 的分组记录，不把本模板的主脸条件套到不露脸编辑角色。

账号ID：待填写；角色ID：待填写；状态：待确认。
主脸：待确认的当前角色资产路径；其他身份参考：仅已获确认的图片。
必须保持：按当前角色实际参考填写；允许变化：服装、配饰、机位、活动等按账号配置。
摄影参考与身份参考分列，摄影获认可不表示人物身份获认可。
`identity.json` 字段：account_id、character_id、version、status、references（role/path/sha256）、retired_identity_files。
图像路径相对 identity.json 所在目录，必须位于当前角色资产根目录。尚无照片时 references 为空、status 为 pending，不填其他角色图片，不宣称已就绪。
摄影路线：从本账号配置读取手机随拍、写真、棚拍等选择范围；按 `visual-continuity.md` 检查人体、皮肤、衣料与环境真实感。
提示词记录：每次保存正向场景/动作/机位/光线/本次成像描述及简短排除项；“真实感”不能只写一个抽象词。
验收记录：身份一致、真人照片感、环境融合、自然表情/视线、机位变化五项分别填写 pass/fail 和可见依据。
