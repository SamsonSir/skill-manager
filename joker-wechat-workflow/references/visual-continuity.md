# 配图连续性与变化

文章和贴图共用当前账号的视觉记录。生图前读取账号视觉规则、身份包、场景登记以及近期已用图；不得只看当前正文就重新设计人物生活环境。账号配置优先，以下为执行方法。

## 场景
- 同一室内空间沿用场景ID、参考图和固定家具。角度变化不等于允许更换沙发、靠垫、墙面或家具关系；未被参考图展示的区域不可声称已确认。新房间或公共室内空间单独登记，不能冒充原客厅。
- 没有固定室内→室外排班。先看内容是否需要特定画面；不需要时按账号偏好和近期重复选择室外人物照、生活环境或无人物风景。情感、阅读题材不自动等于坐沙发；画面可与正文松关联，但不能与明确事实冲突。
- 连续室内、同构图或同活动时，下一张优先尝试其他场景；无需等文章写到出游才可用室外。不得为了轮换编造实际旅行、地点或生活事件。

## 穿搭与机位
- 人物身份参考只锁五官等身份特征，不复制参考中的衣服和首饰。换衣频率服从账号设置及内容所表达日期，同一天同一次活动保持一致；跨日检查重复，不按生成调用次数机械换衣。
- 轮换服装类别、颜色、花型与搭配，不只给同款衣服换色。场景、季节和动作要合理；风格参考借穿搭而不借脸。
- 自拍可为主，也穿插他人随拍；检查距离、高低、朝向、视线和动作的近期重复，保留自然不完美构图，不故意做糊图。
- 配饰按账号偏好，不能因身份参考戴了耳环或项链就每次复制。出现时检查数量、形状、佩戴位置、遮挡和光影；异常就去掉或重做。

## 留存和复用
在账号项目维护配图使用记录，至少包含稿件ID、成品路径、状态（候选/已选/已发布）、内容日期（未知则写未知）、场景ID或场景类型、衣着、配饰、机位、参考与验收结果。文章和贴图一起去重。已确认旧图从证据回填，未知不编；候选不冒充已发布。交付用户只展示成品，记录由 Agent 维护。
